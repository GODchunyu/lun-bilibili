## 1. 测试分层与夹具

- L1 纯函数：固定now、设置/额度/队列/当前操作输入，验证两个通道reason/timeKind/timeAt。使用节点自带node:test，不用真实睡眠。
- L2 Store/调度集成：内存/临时SQLite、分别固定Store容量分配与Scheduler随机源、注入时钟，FakeBilibili的每个网络操作提供可控Promise及调用账本；验证观察层接入前后数据库、随机数计数、外部调用顺序完全相同；比较基准使用S0a修复后的控制语义，S0a明确更正的竞态结果单独断言，不要求保留旧竞态错误。
- L3 API：Fastify app.inject，生产保护fixture传writesEnabled=false、临时凭据路径（HTTP启动应拒绝）；纯Fake允许态另行专用装配，对每个真实fixture校验共享Zod与语义，禁止只断言字段存在。
- L4 前端：提取时钟/轮询/路由纯逻辑可测试；展示TSX独立于CSS与document/localStorage顶层副作用，使用react-dom/server测试静态结构，不直接导入web/main挂载入口。真实React DOM交互、定时器卸载、visibility/focus与响应乱序以浏览器验证，不能用旧settings手写hook夹具替代。
- L5 集成验收：独立loopback端口+临时库+专用Fake服务，真实环境写锁false；如验证页面启动完整流程，只在不可能创建真实桥接的工厂内传createApp(...,true)模拟HTTP允许态，post只写内存Fake日志；浏览器窄屏/深色/桌面检查。绝不读取日常账号数据或触发B站发送。

夹具：now设为上海午夜前后；含不同频道、零额度/用完额度、回复/评论、已改dueAt的capacity_wait、nextPrepareAt、每任务与全局日读取上限、100/200条窗口外任务、在途与已结束uncertain、启动/暂停竞争、长标题与损坏videoJSON、旧版API响应。合成key marker仅用于值脱敏测试。

| D16/P1 | 无任务/全部暂停/全部缺模板/无频道 | 各有中文原因与对应入口；enabled+nextSearch=0应显示待检查而非无任务 |

## 6. 执行门槛与验收步骤

1. S0：独立评审对照计划/测试/约束出具P0/P1/P2；P0/P1必须修订或拆出明确范围，不模糊搁置。S0a单独前置修复O04b/c真实控制竞态；该步骤尚未执行，不能把文档修订算代码缺陷消失。
2. S1/S2：运行相关node:test并验证API只读与调度轨迹；测试不使用真实账号、timer睡眠或随机预期。
3. S3/S4：先提取纯展示TSX供SSR，CSS/document/createRoot/localStorage留在浏览器装配入口；纯函数/SSR加真实DOM或浏览器交互，明确哪个层证明哪些行为。仓库目前无完整浏览器测试依赖，先核对本机可用工具；若需新增依赖先审阅且不擅自升级。无法完成浏览器验收要列“未验收”。
4. S5：三类结果分别记录：①createApp(...,false)的生产HTTP启动必须拒绝；②直接Fake Scheduler.run()只验证调度；③验证启动按钮的完整路径使用专用Fake应用createApp(...,true)模拟HTTP允许态，真实环境写锁false、不创建McpBilibili、不启动Python、不读真实凭据、禁止非loopback网络，post仅Fake内存日志。先断言Fake隔离再完整走：启动暂停→启动检查→搜索等待/搜索中→计划到期→间隔/额度受阻→读取/发送→成功/uncertain→人工入口→暂停中/已暂停→断线恢复。模拟账本与页面逐项对照。
5. 必跑命令（PowerShell，仓库根目录）：

```powershell
$env:BILIBILI_WRITES_ENABLED='false'
npm test
npm run lint
npm run build
git diff --check
```

每条命令分别检查exit code。bridge未改不强制改动Python测试；如改变bridge必须补并运行Python unittest。测试夹具与检查不读取日常数据库，构建不等于重启在用服务。

验收记录表：时间/commit/环境与时区、fixture、实际命令exit code与测试通过/失败/跳过数、浏览器/尺寸/主题、每个用例证据、数据库只读比对、已知限制及未验收项。历史40通过/55skip是上一次记录，不是本轮测试结果。

用户体验门槛：给不熟代码的用户看正常/冷却/待核实/离线四张页面，每张10秒内能指出当前状态、搜索安排、互动安排、要不要人工及入口；看不懂的文案必须再简化。不能把“用户理解”用源码断言替代。

回退：先保持安全暂停，回退观察层与静态产物，保留数据库/attempt/事件；不删除不确定或已成功历史；本轮不实际执行回退。

## 7. 新增装配与统计验收要求

- 装配失败测试：Fake工厂若接收到真实桥接实例/真实凭据路径/非loopback目标，必须拒绝；这项隔离测试先于浏览器启动按钮用例。
- `Store.anyRequestInFlight()`屏障夹具包含“历史attempt残留在途标志、最新attempt无标志”，展示不能比当前执行器更宽松。
- 需要处理卡的总数和已在处理/待人工数分别解释；API原因列表可完整，首页只显示主原因，详情可展开。
- 本轮独立评审仅运行过两个内存Fake竞态取证，未执行本文件完整用例；O04b是已证实的现有缺陷，不代表本计划已经修复。
